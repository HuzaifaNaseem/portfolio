# Portfolio — Muhammad Huzaifa Naseem

My personal developer portfolio. Built without a framework — vanilla HTML, CSS, and JavaScript with GSAP animations.

Live at: [huzaifanaseem-portfolio.netlify.app](https://huzaifanaseem-portfolio.netlify.app/)

---

## What It Includes

- Hero section with animated headline and production-proof subline
- About section with education timeline and stats
- Skills grid with categorised tech tags
- Featured projects section (NatureQuery, VeloCart, Solventix + more)
- Contact section
- Light/dark theme toggle with localStorage persistence
- GSAP scroll-triggered animations, letter-by-letter text reveals, and magnetic button effects
- Fully responsive — mobile, tablet, desktop

---

## Tech

| Technology | Purpose |
|---|---|
| HTML5 | Semantic markup |
| CSS3 | Design system via CSS variables, responsive layout |
| JavaScript (ES6+) | Theme toggle, navigation, scroll behaviour |
| GSAP 3 + ScrollTrigger | Cinematic entrance and scroll animations |
| Netlify | Deployment |
