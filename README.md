# Muhammad Huzaifa Naseem - Portfolio Website

A modern, professional portfolio website showcasing my projects, skills, and experience as a Computer Science student and Full Stack Developer.

## 🚀 Features

- **Modern Design**: Dark theme with glassmorphism effects and vibrant gradient accents
- **Smooth Animations**: Scroll-triggered animations, parallax effects, and micro-interactions
- **Fully Responsive**: Optimized for all devices (desktop, tablet, mobile)
- **Interactive Elements**: Hover effects, tilt animations on project cards, and smooth scrolling

## 📝 Customization Guide

### Adding Your Profile Picture

Replace `profile.jpg` with your actual photo. Recommended size: 450x450px or larger (square format).

### Adding Project Screenshots

To add real project screenshots instead of gradient placeholders:

1. Take screenshots of your projects
2. Save them as: `project-juniper.jpg`, `project-brainwave.jpg`, etc.
3. Update the HTML in `index.html` by uncommenting the img tags in each project card
4. Remove the CSS gradient backgrounds from `styles.css` (lines with `.project-card:nth-child(n)`)

### Updating Project Descriptions

Edit the project descriptions in `index.html` under the Projects section. Each project card has:
- Title
- Description
- Tags
- Live link

### Changing Colors

All colors are defined as CSS custom properties in `styles.css` at the top:
- `--color-accent-primary`: Main accent color
- `--color-accent-secondary`: Secondary accent
- `--gradient-primary`: Main gradient used throughout

## 🌐 Deployment

### Deploy to Netlify (Recommended)

1. Create a GitHub repository and push your code
2. Go to [Netlify](https://netlify.com)
3. Click "New site from Git"
4. Connect your repository
5. Deploy!

### Deploy to GitHub Pages

1. Create a GitHub repository
2. Push your code
3. Go to Settings > Pages
4. Select your branch and save
5. Your site will be live at `https://yourusername.github.io/repository-name`
